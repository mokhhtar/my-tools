# URL ↕ Anchor Text ↕ Type ↕ Rel Status ↕ Time (ms) ↕ Issues

What gets analyzed

1
Link extraction Every <a href> on the page is extracted — internal and external — with its anchor text, rel attribute, target, and whether it's an image link.
2
HTTP status check Each link is pinged with an HTTP HEAD request (falling back to GET). The status code, response time, and final redirect URL are recorded.
3
SEO issue detection 13 issue types are flagged per link: empty anchors, generic anchors, broken links, redirects, missing rel="noopener", nofollow, long URLs, HTTP links, and more.
4
Page-level metadata The tool also extracts the page title, meta description, canonical URL, meta robots tag, and H1/H2 counts from the target page.
Requires Backend: This tool needs the devtoolbox-backend Node.js server to crawl sites and bypass CORS.

Run npm install && npm start in the devtoolbox-backend/ folder.
Running online? You must host the backend (e.g. on Render/Fly.io) and set its URL in the settings above, or run it locally and allow "Insecure Content" in your browser settings.
