How it works

1
Client-side resize Your browser resizes the photo to 512×512 before sending — no large files over the network, no server overload.
2
Hair mask generation (CPU) The Flask backend uses MediaPipe Face Mesh and Selfie Segmentation to isolate exactly the hair region. This runs in ~1 second on any CPU.
3
Stable Diffusion Inpainting (HuggingFace) The original photo + hair mask + style prompt are sent to HuggingFace's free inference servers. The AI regenerates only the masked area (~20-40 seconds).
4
Before/After comparison Drag the slider to compare. Download the result or try a different style.
Local backend required: run python app.py inside hairviz-backend/, then set the API URL in the settings panel above. The AI inference itself runs on HuggingFace's servers — your GPU is never used.
